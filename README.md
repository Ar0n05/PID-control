# PID 滑台位移闭环控制实验

这是一个基于 **LabVIEW + NI myRIO** 的 PID 位移闭环控制实验项目。项目通过 myRIO 采集编码器反馈信号，结合 PID 控制算法计算控制量，驱动电机完成目标位移控制，并通过 LabVIEW 前面板观察位移响应曲线、调整 PID 参数和保存实验数据。

本项目适合作为微机控制系统、运动控制、PID 控制算法和 myRIO 实时控制实验的参考工程。

## 项目背景

根据项目中的实验指导书《交流电机微机测控实验台指示书（PID控制）》，本实验目标包括：

- 理解开环控制与闭环控制系统的基本组成和工作原理。
- 掌握电机闭环控制系统的设计、连接和运行方式。
- 理解步进电机正反转及相序驱动原理。
- 掌握 PID 调节原理，并在 LabVIEW 程序中实现 PID 控制。

实验系统以设定位移为目标值，以编码器检测到的实际位移为反馈量。程序将目标位移与实际位移进行比较，得到误差后通过 PID 算法计算控制输出，再调整电机运行状态，使滑台逐步趋近目标位置。

## 控制原理

系统采用闭环反馈控制结构：

1. 在 LabVIEW 前面板设置目标位移和 PID 参数。
2. myRIO 读取编码器反馈，得到当前位移。
3. 程序计算目标位移与当前位移之间的偏差。
4. PID 控制器根据偏差计算控制增量或控制输出。
5. myRIO 通过数字 IO / PWM 等接口驱动电机。
6. 编码器持续反馈实际位移，形成闭环调节。

实验指导书中同时介绍了位置式 PID 和增量式 PID，本项目主要采用增量式 PID 思路，通过移位寄存器保存历史状态，实现连续控制输出更新。

- 编码器
- 电机驱动器
- NI myRIO 数据采集卡
- 接线端子
- 计算机

项目文件中配置的 myRIO 目标设备为：

- 设备名：`NI-myRIO-1900-030f273a`
- myRIO 地址：`172.22.11.2`
- 本机地址：`172.22.11.1`

如需在其他设备上运行，请在 LabVIEW 项目中重新配置 myRIO 目标地址。

## 使用方法

1. 打开 LabVIEW。
2. 打开项目文件 `控制电机.lvproj`。
3. 确认 myRIO 与计算机连接正常，并检查 IP 地址配置。
4. 在项目中打开 myRIO 目标下的 `Main.vi`。
5. 检查电机、驱动器、编码器和接线端子的连接是否正确。
6. 打开实验装置电源。
7. 在前面板设置目标位移及 `Kp`、`Ki`、`Kd` 参数。
8. 点击运行按钮，观察当前位移、目标位移和响应曲线。
9. 系统稳定后，可保存运行数据。
10. 改变 PID 参数，重复实验并比较控制效果。

## 实验数据分析

实验报告可围绕以下内容展开：

- 绘制不同 PID 参数下的位移实时控制趋势图。
- 比较不同参数下的上升时间、峰值时间和最大超调量。
- 分析比例系数 `Kp`、积分系数 `Ki`、微分系数 `Kd` 对系统响应速度、稳态误差和超调的影响。
- 总结参数整定过程中的现象和经验。

## 注意事项

- 运行前请确认电机驱动器、编码器和 myRIO 接线正确。
- 更换 myRIO 设备或网络环境后，需要更新 LabVIEW 项目中的目标设备地址。
- 实验过程中建议从较小的 PID 参数开始调节，避免电机剧烈动作。
- 本项目包含 LabVIEW 二进制 VI 文件，建议使用 LabVIEW 打开、修改和维护。
